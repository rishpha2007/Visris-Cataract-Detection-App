👁️ Visris - AI Cataract Detection App

Visris is an AI-powered mobile application developed to detect cataracts using Deep Learning and image analysis. The application helps in early eye disease prediction by analyzing uploaded eye images through a Flutter frontend and Flask backend.

🚀 Features

- Cataract detection using AI
- Flutter-based mobile application
- Flask backend integration
- Eye image upload and analysis
- Real-time prediction results
- Beginner-friendly healthcare AI project

🛠️ Technologies Used

- Flutter
- Python
- Flask
- TensorFlow / CNN
- Deep Learning
- VS Code

📱 Project Objective

The main objective of this project is to assist in early cataract detection using Artificial Intelligence and mobile technology for faster healthcare support.
